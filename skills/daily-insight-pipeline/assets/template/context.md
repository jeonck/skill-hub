## 판정 시 우선순위
1. 내 환경에 직접 영향을 주는 이슈/변화 → 즉시조치 후보
2. 내 환경에 해당하지만 긴급하지 않은 것 → 백로그 후보
3. 환경과 무관하나 "관심 분야" 세부 주제에 해당 → 학습 후보
4. 그 외 일반 뉴스, 무관 주제, 마케팅성 글, 명시적 제외 항목 → 무관
