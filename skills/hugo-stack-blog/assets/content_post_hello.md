Hugo 블로그에 오신 것을 환영합니다!

이 사이트는 [Hugo](https://gohugo.io/)와 [Stack 테마](https://github.com/CaiJimmy/hugo-theme-stack)로 만들어졌으며, GitHub Pages를 통해 배포되었습니다.

## 시작하며

앞으로 학습한 내용과 프로젝트 경험을 이곳에 기록할 예정입니다.

```bash
hugo new content post/my-first-post.md
```

위 명령으로 새 포스트를 작성할 수 있습니다.
