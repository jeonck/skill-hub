title: 데일리 스탠드업 (Daily Standup)
---

데일리 스탠드업에서 진행 상황과 막힌 지점을 짧게 공유할 때 쓰는 표현을 모았다.
아래 표현들은 실제 스탠드업 녹취에서 뽑았고, 그룹별로 하나씩 골라 그대로 말해보는
방식으로 연습하면 된다.

<details>
<summary>진행 상황 공유</summary>

**"I wrapped up the migration script yesterday."** (어제 마이그레이션 스크립트를 마무리했습니다)

- 핵심: `wrap up`은 "끝냈다"를 가볍게 전하는 표현이다. `finish`보다 구어적이고,
  큰 성과처럼 들리지 않으면서 완료를 분명히 알린다. 스탠드업처럼 짧게 말해야 하는
  자리에서 자연스럽다.
- 원문: *"I wrapped up the migration script yesterday, so that's off my plate."*
- 유사 표현: I finished up / I got through

**"I'm about halfway through the API refactor."** (API 리팩터링은 절반쯤 진행됐습니다)

- 핵심: 완료도 미완료도 아닌 상태를 숫자 없이 전한다. `halfway through`는 진행률을
  묻는 후속 질문을 미리 막아주는 표현이라 스탠드업에서 자주 쓰인다.
- 원문: *"I'm about halfway through the API refactor — should be done by Thursday."*
- 유사 표현: I'm partway through / I've made a good dent in

</details>

<details>
<summary>막힌 지점 알리기</summary>

**"I'm blocked on the staging credentials."** (스테이징 인증 정보 때문에 막혀 있습니다)

- 핵심: `blocked on X`는 "내 잘못이 아니라 X를 기다리는 중"이라는 뜻을 비난 없이
  전한다. 스탠드업의 핵심 기능이 블로커 공유이므로 이 표현을 쓰면 팀이 바로
  조치할 대상을 안다.
- 원문: *"I'm blocked on the staging credentials — I pinged infra yesterday."*
- 유사 표현: I'm held up by / I'm waiting on

**"It's not urgent, but it'll become a blocker by Friday."** (급하진 않지만 금요일이면 블로커가 됩니다)

- 핵심: 지금은 문제가 아니지만 곧 문제가 된다는 것을 미리 알린다. 긴급도를 부풀리지
  않으면서 기한을 못 박아, 요청이 잊히지 않게 만드는 화법이다.
- 원문: *"It's not urgent, but it'll become a blocker by Friday if we don't have access."*
- 유사 표현: No rush for now, but / It'll turn into a problem if

</details>

<details>
<summary>도움 요청과 조율</summary>

**"Could I grab ten minutes with you after this?"** (이거 끝나고 10분만 시간 될까요?)

- 핵심: `grab ten minutes`는 시간을 구체적으로 한정해 부담을 낮춘다. 스탠드업을
  길게 끌지 않고 상세 논의를 뒤로 빼는, 회의 예절에 맞는 방식이다.
- 원문: *"Could I grab ten minutes with you after this to go over the schema?"*
- 유사 표현: Do you have a few minutes later / Can we sync offline

**"Let's take that offline."** (그 얘기는 따로 하시죠)

- 핵심: 스탠드업에서 특정 주제로 논의가 길어질 때 쓰는 정형 표현이다. 상대를
  끊는 것처럼 들리지 않으면서 회의를 제자리로 돌린다.
- 원문: *"Good question — let's take that offline so we don't hold everyone up."*
- 유사 표현: Let's follow up after / Let's park that for now

</details>

:::tip 💡 팁
스탠드업은 "무엇을 했는가"보다 **"무엇이 막혔는가"**를 듣는 자리다. 진행 상황은
한 문장으로 줄이고, 블로커에는 누가 무엇을 해줘야 하는지까지 붙여 말하면 회의가
짧아지고 실제로 해결된다.
:::
